# vsPropPluginForTPTP
TPTP VS Code plugin for propositional logic. See [tptp.org](tptp.org).

## Testing

1. git clone
2. Open in VS Code.
3. Get dependencies with ```npm install```
4. Compile with ```npx tsc```. This will "compile" the src/extension.ts file, and create an extension.js in the out folder.
5. Open the extension.js file in the out folder. Hit F5 to launch the Extension Development Host.
6. Open or create a .fof file. This extension activates on .fof files only.
